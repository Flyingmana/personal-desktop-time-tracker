# Example Story: Log an hour of work

> This is a template/example. Copy this folder's structure for real stories and delete this note.

## User Story

As a user, I want to log an hour of work with one click, so that I can track my worked time
throughout the day without manual data entry.

## Acceptance Criteria

- **Given** the app is open, **when** I click "Log an hour", **then** the displayed hour count
  increases by one.
- **Given** the app has just started, **when** no hours have been logged yet, **then** the count
  displays "Hours logged: 0".
- **Given** I have logged hours in a session, **when** I restart the app, **then** the count is
  *not* required to persist (out of scope for this example story).
